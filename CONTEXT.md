# Domain Model: AutomatedEDA

## Glossary

### Ticket
A GitHub issue tracking unit of work with defined scope and acceptance criteria.

### Acceptance Criterion
A mandatory verification condition associated with a Ticket that must be tested and proven before ticket closure.

### Headless Plot Persistence
The behavior of saving generated plots directly to disk in non-interactive mode instead of rendering them via interactive display calls (`plt.show()`).

### Metadata JSON Logging
The structured serialization of execution parameters, timestamps, and artifacts into a JSON record alongside generated outputs.
